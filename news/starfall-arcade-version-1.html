STARFALL ARCADE UPDATE

Starfall Arcade Version 1 expands

August 2026PlatformVersion 1

Starfall Arcade Version 1 is growing from a simple game directory into a real platform foundation.

What changed

The hub now includes browser-local player profiles, achievement tracking, Continue Playing shortcuts, recent activity, a stronger game library, a public roadmap, community planning, supporter planning, and a future leaderboard page.

Why the profile is local

A static GitHub Pages site cannot safely provide real authentication by itself. Version 1 is explicit about this: the profile is stored in the browser, while secure accounts and cross-device sync remain future backend work.

What stays separate

Starfall Arcade does not access Stable Empire save data. The two projects remain separated so the hub can evolve without risking game progress.
