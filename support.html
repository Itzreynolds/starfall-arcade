SUPPORT STARFALL ARCADE

Support should add more, not take away.

Starfall Arcade can eventually fund continued development through optional benefits without making the core game experience pay-to-win.

CURRENT STATUS

Nothing is being sold yet.

The supporter page is intentionally prepared before payments are activated so pricing, benefits, licensing, and player expectations can be designed properly first.

STATUSPLANNING ONLYNo active checkout or membership.

Possible supporter benefits

  • Supporter Discord role
  • Development previews
  • Optional cosmetic themes
  • Profile badges when profiles exist
  • Selected beta/testing access
  • Ad-free site option if ads are ever introduced

What should remain protected

  • Core game balance
  • No paid stat advantages
  • No required payment to keep an existing save
  • Clear commercial-use rights for paid assets
  • Transparent pricing and benefits
  • Player trust before aggressive monetization
