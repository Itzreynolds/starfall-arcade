# Starfall Arcade

**A universe of browser games.**

Static GitHub Pages game hub.

## Files
- `index.html` — full website
- `styles.css` — visual design
- `site-config.js` — games, updates, and future Discord link
- `app.js` — filters, cards, navigation, and starfield
- `favicon.svg` — Starfall Arcade icon

## Publish
Upload all files to the root of `Itzreynolds/starfall-arcade`, then go to **Settings → Pages → Deploy from a branch → main → /(root)**.

Expected URL: `https://itzreynolds.github.io/starfall-arcade/`

## Add Discord later
Edit `discordUrl` in `site-config.js`.

## Add games later
Add another object to the `games` array in `site-config.js`.
